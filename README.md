
I build **programming languages** and the runtimes that make them worth using.
MSc student at Institute of Science Tokyo, working on the **semantics of reactive
programming**. I mainly write PureScript and Haskell — and I also draw and compose.

## ✨ Now

#### 🗣️ [Katari](https://github.com/yukikurage/katari)
A programming language for orchestrating AI agents. Durable by default, algebraic
effects for human-in-the-loop, JSON Schema derived from types.
**Running in production as a Discord bot.**
→ [設計について書いた記事](https://zenn.dev/yukikurage/articles/201f6f9155f3db)

<sub>I've built a language before — *memento*, a compiled language in Haskell, with an LSP and a VS Code extension.</sub>

#### 🌊 Quon
Semantics of reactive programming and component systems. My master's thesis.

#### 🌟 [Stellagate](https://x.com/stellagate_traP)
A puzzle game. I'm the director, and I wrote most of the code, drew most of the
pixel art, and composed part of the soundtrack.

## 🧰 Projects

#### 🍮 [purescript-jelly](https://github.com/yukikurage/purescript-jelly)
A reactive UI framework for PureScript with no virtual DOM. — [Docs](https://jelly.yukikurage.net/)

#### 🧠 [brainf__k](https://yukikurage.github.io/brainf__k)
An extremely fast in-browser Brainfuck interpreter (WebAssembly + Web Worker).

#### 🌲 [purescript-dependency-graph](https://github.com/yukikurage/purescript-dependency-graph)
Draws PureScript inter-module dependencies with mermaid.

#### 🤔 [YUKILOGIC](https://yukikurage.github.io/logic-circuit) · 🎆 [MANDELBROT](https://yukikurage.github.io/mandelbrot/)
A logical formula parser, and a Mandelbrot set renderer in WebGL.
